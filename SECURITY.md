# Security policy

Report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/kianbb/kiarakraft/security/advisories/new). Include the affected revision, impact and steps to reproduce with synthetic data. Redact credentials and personal information, and keep sensitive details out of public issues and pull requests.

Use the isolated [development workflow](docs/development.md) for verification. Obtain explicit authorization before testing any hosted system. Maintainers triage reports privately and coordinate remediation and disclosure.
